```markdown
## 1. 目的
[这条流程回答什么问题]

## 2. 范围
- 起点：
- 终点：
- 不覆盖什么：

## 3. 主流程
1. [步骤 1]
2. [步骤 2]
3. [步骤 3]

## 4. 关键状态与分支
- 状态持有者：
- 分发方式：
- 关键判断条件：

## 5. 异常分支
- [异常场景 A]
- [异常场景 B]

## 6. 对应结构体
- [这个流程涉及哪些结构体]

## 7. 对应数据流文档
- [关联的数据流文档名]

```

## 拆分版建议

复杂流程建议至少拆成：

- `xxx-overview.md`：问题范围、阅读顺序、子图索引
- `xxx-main.md`：主流程图与简述
- `xxx-exceptions.md`：异常、超时、失败与回退流程
