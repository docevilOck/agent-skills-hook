## 拆分版建议

复杂数据流建议至少拆成：

- `xxx-overview.md`：总览、边界、简图、子文档索引
- `xxx-details.md`：逐步骤细节
- `xxx-errors.md`：错误路径和回退
- `xxx-states.md`：状态迁移与持有者
