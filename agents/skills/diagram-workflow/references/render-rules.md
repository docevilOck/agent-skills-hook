# 渲染规则

## 唯一产物

- `.md` 是唯一产物，ASCII 图直接写在 fenced code block 中
- 不再经过 PlantUML 或任何中间渲染工具
- AI 按 ASCII 图绘制规范直接手写

## 更新策略

- **纯图文档**（只有标题、ASCII 图、极少量备注）：整份刷新
- **带正文的图文档**（含分析说明、表格、补充备注）：只替换对应图块

## 文件命名

- 文件名格式：`YY-MM-DD_name.md`
- 同一组图文档保持此命名约定

## Markdown 排版

1. 标题
2. 一句话说明用途
3. ASCII 图（放在 fenced code block 里）
4. 必要时补一小段说明或小表

## 可读性

- 标签要短，但必须有语义
- 一张图只回答一个问题
- 图一旦开始拥挤，就拆成多张
- ASCII 是默认输出
- SVG 只在确实有帮助时作为补充
