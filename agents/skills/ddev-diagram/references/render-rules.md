# 渲染规则

## 唯一产物

- `.md` 是唯一产物，图写在 fenced code block 中
- **默认 Mermaid**：能用 Mermaid 表达就用 ```mermaid
- **退回 Unicode 框图**：Mermaid 表达不了时用 `text` 代码块手写 Unicode 制表符框图
- 不再经过 PlantUML 或任何中间渲染工具，不留 `.puml` 源文件
- 同一图块只使用一种语法，不混排 Mermaid 与手写框图

## 更新策略

- **纯图文档**（只有标题、图、极少量备注）：整份刷新
- **带正文的图文档**（含分析说明、表格、补充备注）：只替换对应图块
- 换图型时连同语言标记替换整个 code block

## 文件命名

- 文件名格式：`YY-MM-DD_name.md`
- 同一组图文档保持此命名约定

## Markdown 排版

1. 标题
2. 一句话说明用途
3. 图（`mermaid` 或 `text` fenced code block）
4. 必要时补一小段说明或小表

## 可读性

- 标签要短，但必须有语义
- 一张图只回答一个问题
- 图一旦开始拥挤，就拆成多张
- Mermaid 是默认输出，Unicode 框图是退回路径
- 退回时用一句话说明退回原因
- 默认不加颜色样式；颜色不承载语义
